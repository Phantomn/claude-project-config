# AKM Dimensions v1.2 — 서술 축 산출 명세 (채점 아님)

채점(25기준·0-100 총점)은 v1.1 그대로다. 이 문서는 점수의 해석 좌표계인 서술 축 3종(S·A·O)의 실측 방법을 정의한다. 전문(이론 근거·시각화 문법 포함): https://akm.cmdspace.work/dimensions.html

## 원칙

- 서술 축은 **점수에 반영되지 않는다** — 프로파일 정보다.
- 전 필드 **카운트 기반 실측** — 자기보고 문장 금지, 추정 금지. 실측 불가 필드는 `null` + 사유.
- 표준 표기: `M {총점} ({밴드}) · S-{밴드} · A {percent}% · O{밴드}`

## S — Scale (규모·복잡도 지수)

7필드 각 0-3 (로그 스케일 임계) → 평균 = S-index (소수 둘째 자리) → 밴드.

| 필드 | 실측 방법 | 0 | 1 | 2 | 3 |
|------|-----------|---|---|---|---|
| notes | 지식 문서 카운트 (`find ... -name "*.md" \| wc -l` 등) | <300 | 300-1,499 | 1,500-5,999 | ≥6,000 |
| stores | 활성 지식 저장소(볼트·레포·위키) 수 | 1 | 2 | 3-5 | ≥6 |
| runtimes | 연동 에이전트 런타임 수 (runtime-paths.md 탐지 결과) | 1 | 2 | 3-4 | ≥5 |
| automations | 상시 자동화 잡 수 (launchd/cron/훅 카운트) | 0 | 1-2 | 3-5 | ≥6 |
| skills | 커스텀 스킬+커맨드 수 | <5 | 5-19 | 20-49 | ≥50 |
| humans | 거버넌스 참여 인원 (저장소별 합의 멤버 합집합) | 1 | 2 | 3-5 | ≥6 |
| yearsActive | 운영 연차 (최초 노트·커밋 시점부터) | <1 | 1-1.9 | 2-3.9 | ≥4 |

**밴드**: S-index <0.75 → `S` · <1.5 → `M` · <2.25 → `L` · ≥2.25 → `XL`

## A — Autonomy (자율운영도)

표준 운영 8종 체크리스트. 각 항목: 없음 `none`(0) / 수동 `manual`(0.5) / 자동 `auto`(1). **A = Σ/8** (0-1, % 표기).

| 키 | 항목 | "자동" 판정 예시 |
|----|------|------------------|
| backup | 백업 | 일일 cron 커밋+push |
| indexing | 검색 인덱스·임베딩 갱신 | 저장 훅의 자동 재색인 |
| measurement | 측정·벤치마크 | 주간 측정 스크립트 |
| retrospective | 회고 생성 (위클리·데일리) | 스케줄된 위클리 생성 잡 |
| hygiene | 위생 검사 (드리프트·링크·린트) | 주간 드리프트 체커 |
| secrets | 시크릿·보안 스캔 | pre-commit gitleaks |
| promotion | 지식 승격·편입 파이프라인 | 발행물 자동 스테이징 |
| memoryGc | 메모리·컨텍스트 정리 | 주기적 메모리 정리 잡 |

- "자동" = 스케줄러·훅이 **개시**하고 사람 개입 없이 **완료**. 사람이 결과를 *소비*하는 것은 자동 유지 (소비는 L필러가 채점).
- A는 성숙도가 아니다 — 수동으로도 레벨 4 가능, 자동인데 미성숙 가능. 그래서 별도 축이다.

## O — Output Coupling (산출 결합도)

최근 90일 이 시스템 경유로 제3자에게 전달된 산출물 수 (발행 글·강의·딜리버러블·릴리스·보고서). 제목·날짜 목록이 증거.

**밴드**: `O0` = 0 · `O1` = 1-2 · `O2` = 3-9 · `O3` = 10+

직업 특성 영향이 크므로 서열이 아니라 프로파일 정보다.

## 코멘터리 (commentary — 권장)

`dimensions.commentary` {ko, en}: 프로파일을 점수와 연결해 읽어주는 정성 해설 3-5문장. 다음 네 가지를 서술하라 — ① 사분면 위치와 그 의미 (쾌속정=작게 완결 / 함대=크게 완결 / 출항 준비=정상 초기 / 과적=규모>운영 경보) ② 정합선 대비 위치: S에 비해 A가 따라오는가(정합) 뒤처지는가(부정합 — 유지 부채 예후) ③ O가 말해주는 것 (지식이 실제로 산출로 나가는가) ④ "이 프로파일에서 이 M은 어떻게 읽어야 하는가" (예: S급 시스템의 M3는 낮은 유지비의 완결, XL급의 M3는 규모 방어에 성공 중인 상태). 축의 값 나열은 금지 — 값은 차트가 보여주므로 해설은 **연결과 예후**만.

## 집계 활용 (참고)

보드에 축적되면 세 가지로 가시화된다: ① 2×2 매트릭스(S×M — 쾌속정/함대/출항 준비/과적) ② 버블 차트(S×A, 크기 O, 색 M밴드) ③ Edwards-Parry 다항회귀 반응표면 (M = f(S, A, S², S×A, A²), 규모-자율화 정합 가설). 통계 게이트: N<30 산점만 · N≥30 등고선 적합 · N≥100 표면 검정. 상세: https://akm.cmdspace.work/dimensions.html
